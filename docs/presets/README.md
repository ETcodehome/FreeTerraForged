# Decorative structured strata

Open **Strata Settings** in the preset editor and enable **Strata Decorator**
and **Structured Rock Layers**. The live cross-section shows beds, seams, and
faults for the current preset and seed. Change the slice, width, or elevation
and hover over a block to identify its material. Turn off **Ore Compatible
Stone Only** to see the full palette, including blackstone, deepslate, and basalt.

The corresponding JSON fields are `miscellaneous.strataDecorator` and
`miscellaneous.structuredStrata`. Tilt and folding, fault throw, intrusion and
unconformity toggles, and bed, seam, and lens dimensions control the
appearance of the rock. Terrain shape, erosion, and rivers use the standard
`1.21.1_unstable` generator.
